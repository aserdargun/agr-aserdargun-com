# AGR working contract

- Build Agora — a bilingual (tr/en) deliberation panel of OpenRouter's `:free` models. A visitor puts a proposition to the panel; every seat answers it alone first, then reads the other seats and answers again. Agora counts that second round itself and shows who dissented. It is the first application in this portfolio that makes a live third-party API call, so the working contract below treats the free tier, not the UI, as the design constraint.
- Architecture is a static site with a bring-your-own-key model. There is no Agora server for inference: the browser calls `openrouter.ai` directly. That is a documented path, not a workaround — `GET /api/v1/models`, `POST /api/v1/chat/completions` and `GET /api/v1/key` all answer with `access-control-allow-origin: *`, and `Authorization`, `HTTP-Referer` and `X-OpenRouter-Title` are all allowed request headers. The key is stored in `localStorage` and is never sent anywhere but OpenRouter. Re-probe those headers before changing the transport.
- `public/staticwebapp.config.json` sets `connect-src 'self' https://openrouter.ai`. Removing the OpenRouter origin breaks every call in production while leaving the build green; that coupling is deliberate and must stay in step with `src/core/openrouter.ts`.
- Source of truth lives in `src/core/` (`types`, `roster`, `parse`, `prompts`, `openrouter`, `engine`, `archive`) and `src/ui/` (`App`, `Panels`, `copy`). The roster is read live from the public catalogue on every load, so nothing about the free tier is hard-coded in the bundle.
- Quota is the product's identity, not a limitation to engineer around. The free tier allows 20 requests per minute and 50 per UTC day, and buying a higher tier is a rejected option. A session costs `2 × seats` requests — one blind call and one floor call each — and the form shows that cost before the run starts. `estimateRequests` is the single place that arithmetic lives; there is no synthesis call, because Agora counts the verdict itself so that no panelist authors the count that judges it.
- Model names must never reach a prompt. The floor round shows other positions under blind seat labels only. `tests/engine.test.ts` fails the build if a provider or model slug appears in any prompt; keep that assertion.
- A model's stated position is a transcript entry, never an evidence record. `lab.manifest.json` uses only the shared `EvidenceKind` vocabulary (`sourced`, `user-input`, `calculated`, `measured`, `estimated`) and adds no new kind. Measured confidence comes from token log-probability and is a fluency measure over the whole answer, not a calibrated confidence in the position; the interface labels it apart from the model's own number, and neither feeds the count, where every readable vote carries equal weight.
- `src/core/roster.ts` keeps an explicit exclusion list with a stated reason. No generic filter can catch `nvidia/nemotron-3.5-content-safety:free`, which reports `output_modalities: ["text"]` and a normal completion ceiling and is identifiable only by purpose. Review that list whenever the free catalogue rotates.
- Answers are read tolerantly. Only a minority of the roster advertises `structured_outputs`, so `src/core/parse.ts` extracts a JSON object when present and otherwise recovers a stance from prose, and marks the recovery non-compliant. A member that ignored the requested shape must stay visible as such; never quietly count it as clean.
- A mid-stream rate limit arrives as an SSE event with `finish_reason: "error"` because the 200 status is already written. `streamChat` surfaces it and the seat records an error instead of a truncated position.
- Keep Turkish and English copy equivalent in `src/ui/copy.ts`. Units and labels that matter — requests, seats, agreement share, `measured` versus `self-reported` — must read the same way in both languages.
- Every build writes `dist/release.json` with `application: "AGR"`, the commit, the build time and per-asset SHA-256 hashes. `npm run verify:artifact` validates the local artifact and `node scripts/verify-live.mjs <host> <sha>` validates the deployed one. The release scripts and contract carry the literal `AGR`; retarget both `scripts/release.mjs` and `scripts/release-contract.mjs` together.
- The dev server uses port 4189 with `--strictPort`; do not displace another listener. Port 4173 is occupied on this machine by a listener outside this workspace — never kill it, and never assume a failing dev server is a repository defect.
- Verify `npm test`, `npm run build`, `npm run verify:artifact` and `git diff --check` before handoff. Browser acceptance runs at 1440×1040 and 390×844; `AGR_E2E_URL=<host>` reuses the suite against production.
- Local work only unless the user authorizes external publication. Pushes to `main` flow through `.github/workflows/deploy-swa-agr-aserdargun-com.yml` to `swa-agr-aserdargun-com` in `rg-agr-aserdargun-com` (West Europe, Free SKU).
