# AGR working contract

- Build Agora — a bilingual (tr/en) deliberation panel of OpenRouter's `:free` models. A visitor puts a topic to the panel; every seat answers it alone first, then answers the other seats by name, and the dissenters are invited back once more. Agora counts the discussion itself, measures convergence, and keeps the dissent visible. It is the first application in this portfolio that makes a live third-party API call, so the working contract below treats the free tier, not the UI, as the design constraint.
- The session is four optional rounds: agenda (panel picks its own topic), blind, floor, convergence. The floor and convergence rounds require each seat to name the seat it is answering; `addressed` is what makes the transcript a debate instead of a row of parallel statements, and an empty `addressed` is shown as empty rather than guessed at.
- Architecture is a static site with a bring-your-own-key model. There is no Agora server for inference: the browser calls `openrouter.ai` directly. That is a documented path, not a workaround — `GET /api/v1/models`, `POST /api/v1/chat/completions` and `GET /api/v1/key` all answer with `access-control-allow-origin: *`, and `Authorization`, `HTTP-Referer` and `X-OpenRouter-Title` are all allowed request headers. The key is stored in `localStorage` and is never sent anywhere but OpenRouter. Re-probe those headers before changing the transport.
- `public/staticwebapp.config.json` sets `connect-src 'self' https://openrouter.ai`. Removing the OpenRouter origin breaks every call in production while leaving the build green; that coupling is deliberate and must stay in step with `src/core/openrouter.ts`.
- Source of truth lives in `src/core/` (`types`, `roster`, `parse`, `prompts`, `openrouter`, `engine`, `archive`, `archive-schema`, `cloud-archive`) and `src/ui/` (`App`, `Tabs`, `Panels`, `Timeline`, `copy`). The archive endpoint is the one piece that runs on the server, in `api/archive/`. The roster is read live from the public catalogue on every load, so nothing about the free tier is hard-coded in the bundle.
- The interface is five tabbed sections, not one page: `panel` (setup and the run), `outcome` (the count and the summary), `transcript` (the whole argument), `archive`, `roster`. The tab follows the session — it stays on the panel while the run is live and opens on the outcome when the count is ready, because the count is what the visitor came for. `src/ui/Tabs.tsx` is the ARIA tabs pattern: inactive panels stay mounted under `hidden` so a running session keeps accumulating rounds while the archive is being read. The quota lives in the tab bar, not in the flow, because budget is neither a result nor a step.
- Seat count is a choice, not a number field, and each choice carries what it will spend; the seated panel is shown with the setup so the models are known before a request is paid for. Live progress comes from the `deps.call` seam in `App.tsx`, which is the only place that knows which model actually answered — `deps.onProgress` fires per dispatch and reports the agenda round as `blind` with the seat marker `agenda`, so it cannot be read as a round name on its own. A finished round is handed to the interface through `RunnerDeps.onRound`, which passes over the very arrays `tally()` was built from: the transcript is written while the panel is still arguing, and it cannot drift from the count because it is the same array. A round that was never spent is never reported.
- Quota is the product's identity, not a limitation to engineer around. The free tier allows 20 requests per minute and 50 per UTC day, and buying a higher tier is a rejected option. `estimateRequests` is the single place the arithmetic lives and it returns a **range**, because the convergence round is only spent on dissenters and nobody knows who those are until the floor round is counted. A five-seat session costs 10 or 15. There is no synthesis call: Agora counts the verdict itself so that no panelist authors the count that judges it.
- Model names must never reach a prompt. The floor round shows other positions under blind seat labels only. `tests/engine.test.ts` fails the build if a provider or model slug appears in any prompt; keep that assertion.
- A model's stated position is a transcript entry, never an evidence record. `lab.manifest.json` uses only the shared `EvidenceKind` vocabulary (`sourced`, `user-input`, `calculated`, `measured`, `estimated`) and adds no new kind. Measured confidence comes from token log-probability and is a fluency measure over the whole answer, not a calibrated confidence in the position; the interface labels it apart from the model's own number, and neither feeds the count, where every readable vote carries equal weight.
- `src/core/roster.ts` keeps an explicit exclusion list with a stated reason. No generic filter can catch `nvidia/nemotron-3.5-content-safety:free`, which reports `output_modalities: ["text"]` and a normal completion ceiling and is identifiable only by purpose. Review that list whenever the free catalogue rotates.
- Answers are read tolerantly. Only a minority of the roster advertises `structured_outputs`, so `src/core/parse.ts` extracts a JSON object when present and otherwise recovers a stance from prose, and marks the recovery non-compliant. A member that ignored the requested shape must stay visible as such; never quietly count it as clean.
- A mid-stream rate limit arrives as an SSE event with `finish_reason: "error"` because the 200 status is already written. `streamChat` surfaces it and the seat records an error instead of a truncated position.
- Keep Turkish and English copy equivalent in `src/ui/copy.ts`. Units and labels that matter — requests, seats, agreement share, `measured` versus `self-reported` — must read the same way in both languages.
- `scripts/archive-contract.mjs` is the archive integrity core and is plain JS on purpose: the browser imports it to validate before offering an export, the Node tool imports it to validate before filing, and the Azure endpoint imports a byte-identical copy of it to validate before writing. It re-derives the count from the stored rounds rather than accepting the stored one, requires the quota counter to prove the declared cost, and refuses a record whose request cost does not match the rounds that were actually run. Its `recount()` mirrors `tally()` in `src/core/engine.ts`; `tests/archive-contract.test.ts` pins the two together, so do not change one without the other. The same file also owns the feed row: `toTimelineRow()` derives a row from the rounds and never reads the stored tally, and `validateTimelineRecord()` re-derives a row's shares from the counts it carries, so a row read back out of storage is checked as strictly as the record it came from.
- The shared record lives in Azure Blob Storage, in `stagrarchive` (`rg-agr-aserdargun-com`, West Europe, Standard LRS, hot), container `sessions`, reached only through `/api/archive` on this same Static Web App. There is still no Agora server for **inference**: the browser calls `openrouter.ai` directly, and the only server-side step is filing and reading a record.
- Nothing that arrives anonymously is stored before the archive contract has checked it. The browser validates a record before offering to file it and the endpoint validates it again; a refusal is returned with every problem listed, not just the first. The browser therefore holds **no storage credential at all**, and `/api` is same-origin, so `connect-src 'self'` already permits it — do not add a Blob origin to the CSP.
- Managed functions on Static Web Apps have no managed identity, so the endpoint authenticates with a **container-scoped service SAS** held in the `AZURE_STORAGE_TARGET` app setting, signed for `r`, `a`, `c` and `l` only. It can create and append; it can never overwrite or delete a stored record, so the credential itself is append-only. The container has no anonymous access. Rotating it is one command (`az storage container generate-sas` with `--permissions racl`, then `az staticwebapp appsettings set`), and the current one expires 2027-10-04.
- Two writes per session, one read per page load: `records/<id>.json` holds the record and `index.json` is an append-only log of feed rows. A read-modify-write index would spend one of the 20,000 free monthly reads on every session, so appending is what keeps the budget. The free tier allows 5 GB with 20,000 reads and **10,000 writes a month** (always free), so the store holds roughly 5,000 sessions a month. Because the index is a log, a repeated id resolves to the last row written, and a torn line is counted rather than fatal.
- The read path never trusts what it found: every stored row is re-checked with `validateTimelineRecord` before it is shown, and a row that fails is dropped and counted rather than displayed. A failed read **empties** the feed instead of leaving rows of unknown age on screen, and a 200 that is not the endpoint's own JSON answer — a static host rewriting `/api/archive` to the app shell, for instance — is reported as unreachable, never as a stored record.
- The deploy workflow uploads the static app prebuilt because `npm run build` is what validates the hashes in it, but the API is built by Oryx: `skip_app_build: true` must stay while `skip_api_build` must not. `scripts/sync-api-contract.mjs` copies the contract into `api/lib/` before the upload; that copy is generated, gitignored, and pinned byte-for-byte by a test, so the endpoint can never quietly run a second version of the rule.
- The repository filing path stays: `scripts/archive.mjs` still validates and builds `archive/*.json` into the bundle, and the timeline merges those reviewed records with the live archive by id.
- Panel-chosen topics are grouped by stemmed word overlap above a declared threshold. The stemmer exists because `prevents`/`prevent` and `types`/`type` are otherwise different terms and the panel loses its own shared agenda. Grouping stays a declared heuristic: every group is shown with its size, and the visitor chooses what is debated.
- Convergence is measured against `AGREEMENT_THRESHOLD`, a declared constant, and `held` means a seat that was invited back and refused to move — not every seat that did not move. A seat that was never invited is not held; it was never asked.
- Every build writes `dist/release.json` with `application: "AGR"`, the commit, the build time and per-asset SHA-256 hashes. `npm run verify:artifact` validates the local artifact and `node scripts/verify-live.mjs <host> <sha>` validates the deployed one. The release scripts and contract carry the literal `AGR`; retarget both `scripts/release.mjs` and `scripts/release-contract.mjs` together.
- The dev server uses port 4189 with `--strictPort`; do not displace another listener. Port 4173 is occupied on this machine by a listener outside this workspace — never kill it, and never assume a failing dev server is a repository defect.
- `npm run build` runs lint, the vitest suite, the archive build, the type check, the bundle and the release write, in that order, so the timeline in the bundle is always one the archive validated. `src/data/timeline.generated.json` is build output and is never committed: it can contain a visitor's private session.
- Verify `npm test`, `npm run build`, `npm run verify:artifact`, `npm run test:e2e` and `git diff --check` before handoff. `AGR_LIVE=1 npm test` additionally reads the real OpenRouter catalogue, which is public and free; use it whenever the roster curation changes. Browser acceptance runs at 1440×1040 and 390×844; `AGR_E2E_URL=<host>` reuses the suite against production.
- Local work only unless the user authorizes external publication. Pushes to `main` flow through `.github/workflows/deploy-swa-agr-aserdargun-com.yml` to `swa-agr-aserdargun-com` in `rg-agr-aserdargun-com` (West Europe, Free SKU).
